CANADA PREDICTION FINDER / VERSION 3.1

This edition runs on GitHub.

Upload the extracted project files into a separate repository. Your Mac does not need to remain awake once GitHub scheduling is enabled.

Open GITHUB_SETUP.md for the full installation steps.

Include the hidden .github folder. Do not upload just the ZIP. Set the state-encryption secret, initialize once, test a scan, then enable scheduling.

The default trial uses US$500 of simulated funds for seven days. It requests one-minute scans within five-minute scheduled batches, with possible gaps. Private-repository runner costs require explicit acknowledgement. Public dashboard publication is optional.

Not a proven profitable strategy. No live-order or Canadian brokerage connection is implemented. Missing prices are not replaced with fabricated profits.

See README.md for capabilities and limitations. The retained Mac launchers are optional local tools, not the primary deployment instructions.
