Canada Prediction Finder / Research Lab / Version 3.0

Your Mac is the lab.
Evidence comes before funding.

One-minute target scanning. A persistent US$500 paper portfolio. A local dashboard. No account credentials or real-money orders.

This is not a proven profit bot.
The implemented feed is public Kalshi research data—not verified Canadian brokerage quotes. ForecastEx, IBKR Canada and Wealthsimple are not connected. No live-trading feature exists. Demo results are fabricated software tests.
01 / INSTALL

Unzip, then install.

Put this entire folder somewhere permanent. Double-click Install.command. It checks Python 3.10+, creates a local environment and runs the offline tests. Nothing is installed into your DEX projects.

02 / CHECK

Verify your data feed.

Double-click Check.command. It tests the official keyless public endpoint from your Mac. A failed or denied connection is not permission to bypass a restriction. No fake data will replace a failed feed.

03 / START

Run the paper trial.

Double-click Start.command. Your browser opens the dashboard. Keep the Terminal process running, the Mac awake and the network connected. Use Control-C in Terminal to stop.

Python not installed? Use the official Python macOS download page, then rerun the installer. These are unsigned scripts, not a notarized native application. When needed, review the file, then run it from Terminal with bash followed by the dragged-in script path. Never disable system security globally.

What should happen first?

The real-data ledger starts at US$500 with zero trades. Catalog discovery precedes strategy warm-up. Automatic reversion research needs roughly an hour of uninterrupted observations on stable watched markets, often longer after gaps. It then waits for a candidate to survive fees, depth, risk limits and a second scan. It may make no trades. A quiet scanner is not necessarily broken.

Warm-up and scans are not wins. The experimental strategy looks for price reversion; it does not know future outcomes. Independent-value research requires a separately justified probability forecast entered in the dashboard. No hidden AI subscription or automatic expert forecast service is connected.

Your results survive restarts.

Private files live outside this code folder in ~/Library/Application Support/CanadaPredictionFinder/paper/. Demo data is in a separate directory. Code updates do not reset the ledger. Daily local backups retain seven copies; maintain an additional secure off-device backup. Do not publish data or forecasts on GitHub.

Before believing the numbers

A profitable paper chart is not a funded-account result. Unknown liquidity makes equity unavailable rather than fabricating an executable price. Fees are estimates. Missing Canadian broker equivalence is a hard blocker. The built-in research screens cannot enable real orders—even when every screen passes.
